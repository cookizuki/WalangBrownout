# Walangbrownout Inventory OS

A real-time inventory management system for WalangBrownout Appliances, built to
solve seasonal stockouts, unexplained shrinkage, and FIFO-related expiry losses
through live batch tracking, role-based dashboards, and automated reorder alerts.

## Tech stack
- Frontend: React (TanStack Start)
- Backend: Laravel (planned)
- Styling: Tailwind CSS

## Development

```sh
git clone <this-repository-url>
cd walangbrownout-inventory-os
npm install
npm run dev
```
